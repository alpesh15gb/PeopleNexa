## Local verification

- The production build passed TypeScript and opened all 64 tenant portal routes with administrator or employee credentials. This included the canonical redirects from the old employee and payroll routes.
- Authenticated workflow checks covered employee revisions, import rollback, transfers, onboarding and exits, helpdesk, asset custody, performance feedback, audit search, workspaces and notification access. Local browser checks also covered management navigation, approvals, forms, reporting, and narrow layouts.
- PostgreSQL failure-injection and concurrency checks covered punch reconciliation, correction and face approval rollback, leave dates and roster overwrite. Payroll checks covered draft recalculation, independent review, simulated settlement, and scoped cashbook totals.
- Platform checks verified immediate suspension and module enforcement, license history and plan transitions, and hiding connection secrets from ordinary reads. Webhook receipt handling used a simulated receiver. No production deployment or physical device operation was used for these checks.

The production build and 63 regression scripts passed. Live bank settlement, real devices, and the legacy workbook lifecycle remain separate staging checks.

## Full screen follow-up

The [screen revamp ledger](screen-revamp-ledger.md) covers all 71 page routes, including the two legacy redirects. Employee and manager leave histories now page on the server, with separate request and calendar views. The dashboard routes into scoped review queues and the dashboard layout editor. Mobile punch searches and roster data loads keep the location manager’s authorization scope. Daily and monthly device reports, punch-detail views, and historical journey replay use the workspace time zone. Stored attendance dates and payroll calculations retain their existing date conventions.
